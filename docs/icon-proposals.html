SpecReader AI 图标设计方案

目标：让标题栏图标（22px SVG）与应用图标（Dock / 任务栏 / 安装包）匹配新的「暖纸色系 Paper Workbench」——纸面色阶 + 暖棕文字 + 唯一焦橙强调色。蓝色只保留给解读语义，不再出现在品牌图标里。

A

书签条款

Bookmarked Clause

一页标准文本 + 探出页边的焦橙书签。书签表达「正在精读、随时回到这条款」，是阅读器最经典的隐喻；页面里再压一条橙色高亮行，呼应选中文本 → 解读的核心闭环。与现有图标一样以「文档」为主体，用户认知零成本切换。

B

§ 条款印记

Section Mark

「§」是法律与标准文献中「条款」的通用符号——对每天查 IEC 条款的工程师来说一击即中。焦橙实底 + 纸白字形，是四个方案中最大胆、Dock 里最容易一眼认出的一个；气质接近 Bear / Things 这类单字形图标。

C

检索之镜

Reading Lens

文档 + 右下角焦橙放大镜，直接翻译「Spec / Reader」：在标准里检索、放大、细读。镜片填了 #ffe3d4 橙雾色，既呼应 --accent-soft，又让镜片有「玻璃」的体积感。隐喻覆盖面比书签更广（搜索、细读、审查都算）。

D

星芒解读

Spark Insight · 现款重配色

保留现有图标的构图（文档 + 右下角 AI 角标），只做「换血」：蓝紫渐变 → 焦橙，冷蓝文本行 → 暖棕色阶，五角星 → 四芒星（更贴近当下 AI 闪烁符号的通用语言）。改动最小、品牌连续性最强，老用户不会「认不出」。右侧面板的解读蓝色标记不受影响。

我的推荐：A 主推，B 备选。 A 在「阅读器」隐喻、小尺寸轮廓、明暗主题适应性之间最均衡，且与现款文档构图有连续性；如果你更想要 Dock 里一眼跳出的品牌符号、并且目标用户（标准工程师）对 § 有天然亲近感，选 B。也可以混搭：应用图标用 B（单字形最醒目），标题栏用 A（与旁边品牌名的图文组合更柔和）——两者色系完全一致，不会割裂。

落地路径：标题栏 → 把选中方案的 <symbol> 内容存为 public/logo.svg；应用图标 → 用 SVG 导出 1024×1024 PNG 后执行 npx tauri icon <path> 自动重新生成 src-tauri/icons/ 全套尺寸（含 .icns / .ico）。方案 B 的 § 字符务必先转曲再导出。预览中的渐变仅为纸面微光，若追求绝对扁平可去掉。
